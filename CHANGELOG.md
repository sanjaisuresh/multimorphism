# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.2.0] - 2026-09-03

### Added
- Implemented 4 new trending design styles: Spatial (VisionOS), 8-Bit Pixel, Holographic Foil, and Organic/Ecomorphism
- Added preview buttons for the new styles in the Theme Configurator grid

## [0.1.0] - 2026-09-02

### Added
- Created reusable `AppLogo` component
- Integrated Notification Sheet with mock alerts, message handling, and unread badges
- Added custom Favicon to sidebar and top nav for horizontal layouts

### Changed
- Improved User Profile structure by removing generic website placeholders
- Replaced Twitter profile icon with direct Gmail action
- Refactored `DashboardLayout` for robust routing using `Outlet`
- Removed obsolete Dark Sidebar setting logic

### Fixed
- Fixed breadcrumbs rendering overlap in layouts
